## 18：粗钯粉那个甲酸——两个错叠在一起，都跟「物品还是流体」有关

你报的是：「粗钯粉要与甲酸一起才能反应，配方是清楚的，但产线上没有粗钯粉外的那个甲酸，既无点击外原料这个点」。

两个独立的错，都出在**「一个材料到底是物品还是流体」**这件事上。

**错一：甲酸根本没进任何列表。** 甲酸在配方里是**标签输入**（`#forge:formic_acid`），
而标签槽没有自己的 id。构造「外部原料」列表的代码写的是 `val item = s.itemId ?: continue`
——**每个标签槽都被跳过**。而 GregTech 里绝大多数流体输入都是标签，所以
`#forge:formic_acid`、`#forge:hydrochloric_acid` 这些一个都没进列表。现在标签槽展开成它的候选，
按包里标注的 kind 生成键。

**错二：流体被当成物品。** 流体在包里**也有一行物品**（这样它才能有名字、能被搜到），
所以那行和真正的物品长得一模一样。手动添加原料那个框写死了 `"item:${item.id}"`，
而求解器里材料的键是 `"<kind>:<id>"`——**一个用 `item:` 标的流体，求解器永远收不到**，
你填的速率就是个不起作用的数字。

修法是让包来回答：包里现在给**所有被配方当作流体用到的材料**打上 `fluid: true`。
改之前只有 530 行带这个标记，而且全是打包脚本自己造出来的流体行；
甲酸、盐酸、氢这些**真正在化学链里的流体，恰好就是没标记的那些**。
这一版标了 **1,061 行**。App 把标记带进数据库，设速率时先按这条线已经在用的键去找，
找不到才去查包。

**顺带把「点外原料这个点」做实了**：外部原料卡片现在还有一栏**「本线的其它原料」**（默认折叠）——
甲酸在这个包里**是能自己造的**，所以按严格定义它不是「外部原料」，
但你可能就是想从外面运进来，而不是自己搭那一步。以前没有地方说这件事，现在两种情况的入口是同一个：填速率。

## 16：配方有没有漏？现在有工具给出答案了

「不漏配方」这句话我说过好几次，但从来没量过。打包脚本每跑一次都会打印 `dropped 51265 empty`——
这个数字要么是"确实没有材料的配方"，要么是"解析器丢掉了一整类"，**在日志里两者长得一模一样**。

于是写了个审计脚本，把导出器的原始转储和包逐 id 对比。**结论：原始 47,906 条配方，包里一条都不缺**；
包里反而有 55,190 条——多出来的部分是因为**一个 tag 输入会展开成"每个候选物品一条配方"**。
被丢掉的只有"完全没有材料"的配方，那本来就该丢。

（这个脚本第一次跑的时候给出了相反的结论，因为**读错了转储文件**：导出器同时写了一份"注册表"
（斜杠 id、没有材料）和一份"已解析"的转储（包用的下划线 id、带材料）。拿注册表去比，每一条都像丢了。）

## 你报的四件事，是同一个根因，已修

你实测的四条症状我全部复现了，而且它们指向同一类错误。**必须重新导入配方包**（第 6 代）。

**1. 点配方里另一个材料提示"包里没有这个物品"** —— 键的形状有三种（`item:gtceu:x`、`gtceu:x`、`x`），
配方页传的是注册 id，而那段代码按"产线键"去掉了前缀，于是拿 `iridium_chloride_dust` 去查表，永远查不到。
现在三种形状统一由一个查找处理（放在 DAO 旁边，避免两处再走岔）。

**2. 液体只有生产配方、没有消耗配方** —— 这不是界面问题：**输入一直在配方里，但它是"流体标签"，而包把它丢了**。
导出器的键解析在找 `] / ` 这个分隔符，而 `ResourceKey[...]` 和 `TagKey[...]` 两种形式里都没有它，
于是每个流体标签都过不了 id 检查、被静默丢弃——**一次导出丢 15,929 个槽位**。反映到界面上就是：
一条化学链少了酸，一台机器看起来什么都不消耗，一种流体永远有产出没去处。

**3. 标签槽的成员表** —— 打包脚本原来会跳过"没有 id"的槽位（那就是标签），现在保留；
并在流体行存在之后按路径补全成员：**16,208 个槽位补上**，只有标签提到过的流体会为它建行（且必须有名字才建，不会凭空造材料）。

**4. 标签的候选现在也进 uses/makes 索引** —— 消耗 `#forge:acidic_iridium` 的配方会出现在酸性铱的页面上，
而不是哪儿都不出现。每个标签最多 6 个候选，否则一个宽泛的标签会让一条配方出现在几十个页面上。

**验证方式**：导入测试现在断言「有产出配方的流体必须有消耗配方」，跑在真包上——**酸性铱通过**。
（酸性锇在本包里没有任何配方引用，所以它没有行；App 会如实说"这个材料存在但本包没有它的配方"。）
